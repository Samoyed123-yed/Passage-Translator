Actual implementation used:
1. comic-text-detector ONNX weights from manga-image-translator beta-0.3 release.
   https://github.com/zyddnys/manga-image-translator
   Inspected source commit d6de6ab62a7be6afc0d07a3184149cdefbcd32f2.
   Passage uses the released detection weights, not this repository's full application.
2. Lightweight ONNX model adapters vendored from M3MONs/manga-translation.
   https://github.com/M3MONs/manga-translation
   Commit 0d34719560a726458432dd56449d69310c3e27ba, MIT license.
   License is retained in vendor/LICENSE-manga-translation.txt.
   Detection, Japanese/Paddle recognition and LaMa inference adapters are actually called.
   Its NLLB translation and default rendering are not used.
3. Japanese manga-ocr model, ONNX export by dnouv.
   https://github.com/kha-white/manga-ocr
   https://huggingface.co/dnouv/manga-ocr
4. PaddleOCR English/Korean recognizers, ONNX export by monkt.
   https://github.com/PaddlePaddle/PaddleOCR
   https://huggingface.co/monkt/paddleocr-onnx
5. LaMa inpainting, ONNX export by Carve.
   https://github.com/advimman/lama
   https://huggingface.co/Carve/LaMa-ONNX
6. Qwen official Qwen3-4B-GGUF, Q4_K_M.
   https://huggingface.co/Qwen/Qwen3-4B-GGUF
   Apache-2.0 model card.
7. llama.cpp b12024 Windows Vulkan build, MIT project.
   https://github.com/ggml-org/llama.cpp/releases/tag/b12024
8. Qt / PySide6 (LGPL/GPL/commercial options), Pillow, NumPy, OpenCV, ONNX Runtime,
   Requests and their dependencies. Package metadata/licenses retained in .venv.
   Exact installed versions: requirements-lock.txt.
9. Microsoft YaHei, Arial, Yu Gothic and Malgun Gothic are loaded from this Windows
   installation. Windows font files are not copied or redistributed with this project.

Passage additions:
Chinese native desktop UI, recursive read-only scanning, separate atomic PNG output,
source/output hashes and resumable processing, local-only model server, context and
glossary prompts, effect-text filtering, long-image tiling, narration fallback detection,
regular Korean vertical-text assembly, conservative clean-and-render handling, manual
translation correction and rerendering, synthetic samples and integrity tests.

BallonsTranslator and comic-translate were inspected as candidates, not installed as
the application and not represented as the source of this new UI. No claim is made
that all bundled model artifacts share a single license; consult their upstream model
cards before redistributing. This directory is a local working installation.

Release packaging supplement (2026-11-24):
- jieba 0.42.1, MIT: https://github.com/fxsjy/jieba
  Already used by linebreak.py in the source installation; now included in the
  dependency lock so a clean installation preserves word-aware line breaking.
- Original Passage source is MIT licensed; see LICENSE. The historical installation
  notes above describe provenance, not a blanket license for all components.
- Resource Han Rounded CN Medium/Bold/Heavy: SIL Open Font License 1.1.
  https://github.com/CyanoHao/Resource-Han-Rounded/releases/tag/v0.990
  The three unmodified font binaries and fonts/ResourceHanRounded-LICENSE.txt are
  distributed together. They are excluded from the original-code MIT license.
- assets.lock.json records every downloadable asset and each extracted runtime
  member with byte size and SHA-256. Existing local asset hashes were recomputed;
  extra manga-ocr config/tokenizer hashes came from the pinned upstream revision.
- manga-ocr's application adapter currently reads only two ONNX models and vocab.txt.
  The release additionally downloads upstream config and tokenizer metadata, without
  changing that adapter. The downloaded models retain their upstream licenses.
- Both English PP-OCRv6 files and Korean PP-OCRv5 coverage weights are downloaded
  from RapidAI's versioned v3.10.0 ModelScope distribution; Paddle en/ko fallback
  recognizers come from the monkt ONNX export. All are local at application runtime.
- No model or executable runtime is redistributed in this source repository.
  Qt/PySide6 and other Python dependencies are installed as separate packages.
  Their license files remain in the installed environment, not replaced by MIT.
- User images, OCR histories, translation records and private regression crops are
  not part of this release. passage.ico and passage-icon.png are application artwork.
