Passage 1.5.3 · 本地漫画翻译

打开方式
双击桌面的「Passage 本地漫画翻译」快捷方式。
也可以双击本文件夹里的 Launch.vbs，或 Start-Passage.cmd。
当前安装依赖本机 Python 3.13 和此文件夹内 .venv；不要只移动某个启动文件。

操作
1. 选择原图文件夹。软件会递归扫描子文件夹中的图片。
2. 软件自动在同级位置生成「原文件夹名（中译）」，不需要先建文件夹，也不需要选择输出位置。
3. 选择这一批的主要语言：日文、英文或韩文。多语言混合页面尚不自动切换 OCR。
4. 可选：展开「术语与保存位置」，填写称呼/术语词表，例如 Yuki = 由纪。
5. 点击「开始翻译」。完成后可左右对照，滚轮放大，按住拖动。
6. 点击「打开中文版文件夹」查看成品。默认不再有需要逐项处理的校对队列。

输出与原图保护
原图只读。保留原文件名、图片格式、子文件夹结构和原始像素宽高，例如 001.webp 仍为 001.webp。
普通非图片文件原样复制，空子文件夹也保留；不复制 .passage 记录或经过链接跳转的内容。
PNG、WebP 使用无损保存；JPEG 使用高质量重新编码，会存在压缩层面的像素变化。
文件夹位于桌面，中文版就生成在桌面；位于某个目录，中文版就生成在同一个父目录。
如果同名目录已有不属于这次任务的文件，自动使用「（中译 2）」等新名称，不覆盖其他内容。
没有可验证的 Passage 记录时，不会覆盖输出文件夹中已有的同名文件。
成品目录不生成 .passage、校对 JSON 或运行报告，只保留原目录对应的成品文件。
处理中的恢复记录保存在程序自己的 runtime/jobs 目录；成功完成后自动清理逐页记录。
仅保留本机的最小哈希索引，以支持再次点击开始时跳过已完成页面，索引不含识别原文或译文，只增加未译数量和跳过原因统计。
停止会在当前模型调用结束后生效。再次开始时按原图、设置和结果摘要跳过已完成的页面。
改语言或词表会重新处理。修改原图后会重新处理。

支持范围
1.5.3：复杂背景上的已翻译正文使用白底覆盖原文范围，避免生成式修复留下假字；不翻译的特效仍保留。宽于高的短句优先横排，长句和窄长竖条保持原阅读方向，手动方向设置优先。
1.5.2：确认翻译的对白、旁白按完整原文范围清字，译文变短也不缩小清字范围；没有对话框的背景正文允许小范围整块修复，优先清除残字和描边。
不翻译的拟声、纯喊叫及相邻保留区域继续保留原像素。纯喊叫不进入翻译，含有否定、拒绝、请求或正文的句子不会仅因夹有喊叫而跳过。
有可靠边框且留白过多的对话框允许更积极的字号放大；保持原有横竖阅读方向、居中和轮廓限制。
统一风格配置减少重复指代、冗余形容和生硬把被句；成人原文按原意使用直白口语，不医学化，也不添加原文没有的描写或强度。
上述变化适用于之后启动的处理；不会主动重新翻译已经完成的书。更新后关闭并重新打开 Passage，下一次任务即可载入新代码和风格配置。
JPG/JPEG、PNG、WebP、BMP、TIFF、AVIF，以及单帧 GIF；多帧图片原样复制，避免丢失动画或其他页。
优先处理对话、内心独白、规则旁白与悬浮文字。拟声和装饰性特效字由模型筛选，仍可能误判。
日文支持横排及竖排。英文支持全大写。韩文支持横排，规则竖排使用字符重组识别。
长图分块检测，输出不缩小。超过一亿像素的单张图片需要先分段。
纯色区域直接清字，复杂背景使用 LaMa 修复。字体按可用区域缩放。
原文识别仍按实际行列顺序处理，同页可混合横排、竖排，不按整页形状决定。
日文竖排原文按每列从上到下、从右列到左列识别。
1.4 优先保持原文阅读方向，英文默认横排，日文竖排默认保持竖排；不再只因框窄就强制转向。
英文检测到的相邻行先按对话框和段落边界合并；逐行 OCR 后拼成完整段落，只翻译一次再统一嵌字。
低置信度英文会扩大到整段上下文重新检测，倾斜行按四角做透视校正，再用第二路英文识别器读取；合并两次检测结果，保留仍有效的旧行，补回遗漏的首尾行。
英文先去除混入的边线、分离描边与背景，再校正小角度倾斜后分行。紧密换行不会合并成单行；并列段落按分栏分别识别。
识别失败先重新处理局部图像，翻译失败改用逐段重译，避免只翻译开头。英文短句和空识别结果不会直接绕过自动重试。
英文使用本地 PP-OCRv6 对全页检测及识别，结合漫画检测器的笔画掩膜和第二路 OCR，补足小字号、复杂底色上的漏框。
嵌字后重新扫描全页，发现仍与原文匹配的英文词时，区分译文夹带英文和清字残留，自动重译或重新清字。该检查是残留筛查，不等同于语义正确性保证。
横排中文从左到右、从上到下；竖排中文从上到下、从右列到左列。
识别到封闭的白色对话框后，按内部轮廓与几何中心排版；同一框里多块文字分别保留位置，避免互相重叠。
短译文适当放大、长译文缩小和换行；留白明显过多且容得下时，再适度增大约一档字号。
文字像素须落在可用轮廓内；原本已经拥挤的文字不会强行放大。
每个文字区域先采样原文的主要字色，黑字保留黑色、白字保留白色，彩色字沿用主要颜色。
没有可靠对话框轮廓的悬浮文字在原位置范围内缩放、重排；复杂底色使用细描边增加可读性。
中文方向、字号与换行由程序自动选择，不再要求你确认方向。
纯省略号、标点、数字及明确判断为特效的片段保留原样；跳过不代表已翻译。
1.5 起，日文、韩文短句翻译失败也会重试，仍失败则记入未译数量，不再仅因字数少而作为正常跳过项。
韩文存在空识别行或低可信行时触发复核；日文/韩文有意义的单字也进入翻译，不能仅以长度判断为符号。
1.5.1 韩文改用本地 PP-OCRv5 韩文识别器，并复用 PP-OCRv6 行检测器；先按整行读取，再按段落合并后翻译。
倾斜、紧密换行和韩文字母内部空隙分别处理；对白中的爱心保留为符号并随中文一起排版，不能使整句被当作拟声词跳过。
漫画检测器和独立行检测互补：一个检测器漏掉的规则旁白可由另一个补回。明确拟声词与无字形的画面误检测不计入未译数量。
韩文在输出前完成局部识别修复与译文检查，取消仅因未译状态而把整页再跑一次；后续正常任务同样使用此流程。
确认闭合边框的稀疏对话框允许更多中文占用面积，仍受轮廓、居中和相邻文字避让约束。
首次使用 1.5.1 处理旧韩文任务时，会刷新该任务的旧识别缓存；英文和日文缓存不变。
韩语明确禁止、能力否定和陈述否定增加有限的语义检查；日文口语否定与禁止检查保留。规则不能覆盖所有语法或证明语义完全正确。
日文、韩文每组译文会再与原文对照一次，校核增译、遗漏、否定、语气与时间关系。该步骤使用同一本地模型，会增加处理时间；无法通过校核的区域保留原文并计入未解决项。它不能代替人工语义审核。
韩文单独辅音、元音残留也算未完成翻译；竖排列不套用日文注音合并规则。
界面采用浅色纸感，术语和日志按需展开，处理期间才显示停止按钮。小窗口可滚动设置，预览随窗口适配，手动缩放后保持缩放。
日文与韩文尚没有英文那套独立的全页残留 OCR 复核，未知字体、手写字、漏检测和复杂背景仍需抽查。
识别不明确时尝试局部放大重识别；翻译异常时单独重试；缺少清字掩膜时尝试从纯色底恢复笔画。
成品复核未通过时，整页会自动返回识别与翻译流程再试一次，并保留较好的结果。重试次数有上限；再次运行时，仍未解决的页面不会作为已完成缓存跳过。
普通对白的处理失败与正常跳过的拟声、装饰字、标点分别统计。短片段或画面线条仅在复核后分类跳过；仍未解决的普通对白会如实显示未译数量。
高置信度识别为彩色单幅海报的第一页原样复制；不把每本第一页一律当成封面。
白描边不再当成白色对话框；清字包括外描边，透明对话框内的复杂背景交由修复模型处理。
清字或相邻文字冲突无法安全解决时，可整页保留原图。不会将保留原文说成已经翻译成功。
翻译请求使用批内连续编号，结果按编号回填；检查异常扩写和未翻译的日文、韩文、外语短语。
对话采用简短、口语化表达，俚语保持原意与原有粗俗程度。词表仍可用于固定人名和术语。
1.3 的新任务默认使用新的同级「（中译）」目录，不迁移或改写以前已经交付的目录。

翻译风格与术语更新（1.4.1）
默认风格为自然口语，粗俗程度随原文。减少生硬从句、重复主语以及过密的被、把、的；不机械删字，不改施受关系、否定、拒绝、条件和程度。
translation_style.json 保存语气规则和带语境说明的术语；可以单独更新，无需更换或训练模型。instructions 是规则文字列表，terms 的每项含 term、aliases、guidance，可选 source 用于记录词义来源。
程序在每一批任务开始时读取配置，同批首次翻译和自动重译使用同一份配置。软件中填写的人名/术语词表优先于默认术语提示。
日语明确的句末缩略否定与禁止结构会先还原语法再翻译；原文记录不改，同时检查译文是否把事实否定误译成命令或把禁止读成肯定。此检查只覆盖明确结构，不是完整语义验证。
英文术语按完整单词及列出的词形匹配，避免把 strap 等普通词误触发为 trap。日文词条按原文匹配，具体义项仍由上下文决定。
这些规则用于新处理的图片；更新配置不会自动重做已经完成的成品。软件不会通过使用自动训练或自行下载词包，模型本体仍是本地 Qwen3 4B。
对白留白明显过多且识别到可靠对话框时，字号选择允许占用更多可用区域；拥挤对话框和悬浮文字不整体放大，仍检查轮廓和相邻文字。

本地与硬件
此安装针对 Ryzen 7 6800H、16 GB 内存、RTX 3060 Laptop 6 GB 显存配置。
翻译使用官方 Qwen3 4B Q4_K_M，llama.cpp Vulkan 指定本机 NVIDIA 设备。
OCR/检测/清字使用 CPU ONNX Runtime，以免多个模型争抢显存。
模型已下载后，处理不需要外网，不需要 API key 或按页付费。
Python 处理进程拒绝非本机网络连接，翻译子进程开启 offline 模式并只绑定 127.0.0.1。
翻译服务仅在处理期间启动，结束或失败后关闭；没有添加开机自启或系统后台任务。
首次模型下载脚本 setup_models.py 需要联网；日常启动不会调用它。
不要同时打开多个 Passage 处理任务。运行时建议关闭大型游戏和其他占用显存的软件。

质量与限制
词表和同一小批次的对话能改善称呼一致性，不能保证俚语、双关和省略句全部正确。
漫画 OCR 可能误读或遗漏文字；日文识别器没有经过校准的置信度，不能把检测分数当成识别准确率。
复杂背景只能推测被字遮挡的画面，可能出现修复痕迹；特效字筛选也不是绝对可靠。
自动检查能验证文件完整性、排版边界和处理状态，不等同于逐句人工译审。
模型可能在没有报错的情况下译错人称、俚语或双关；自动模式不能保证每句语义正确。
渐变字、同一块文字里的多种颜色目前使用主要字色，不能逐字还原渐变、纹理和原字体。
对话框轮廓不可靠时使用原文字范围排版；无法安全处理时保留原文，避免任意覆盖画面。
原文区域内部的行列顺序按文字方向处理；不同对话框之间仍使用位置近似，复杂分镜可能影响上下文顺序。
图像方向元数据不自动旋转：保持存储像素的宽高。扫描漫画通常不受影响。

问题定位
完成摘要显示在软件下方；新的成品目录不再附带运行报告。
runtime/last-error.txt 保存应用异常；runtime/llama.log 保存本地推理启动日志。
如果显存不足或服务启动失败，先停止其他大型本地模型，再重新开始。
evidence/ 是本次安装的测试记录；examples/ 是普通测试页及其结果。

开源出处详见 THIRD_PARTY.txt；已下载模型的地址、大小与 SHA-256 见 models/manifest.json。
